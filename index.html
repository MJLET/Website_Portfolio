AEGIS: an AI diagnostic system for a computer lab

Capstone · Cebu Eastern College, Incorporated · IT Department Computer Laboratory

AEGIS is a client-server system that checks lab PCs automatically, shows their health live, and predicts which machines will need maintenance before they break.

The problem
Technicians checked lab computers one by one. Faults surfaced during class, and maintenance was reactive, with no record of which machines kept failing.
The solution
A lightweight client on each PC reports hardware and software diagnostics to a central server. A dashboard shows live status, and predictive analytics flags machines likely to need service.
My role
UI/UX design and web development. I designed the dashboard and status system in Figma, built the front end, and connected it to the diagnostics and prediction data.
Tech stack
Figma HTML5 / CSS3 / JavaScript Tailwind CSS Node.js / PHP REST API SQL Python

Design system

One three-state colour code (healthy, watch, at risk) used across every workstation tile, chart and alert, so a technician reads the lab’s condition at a glance. Dashboards put the machines needing action first.

Technical integration

Client agents send diagnostics to the server in real time. The dashboard reads that stream for live monitoring and feeds the history into the predictive model for maintenance forecasts.

Impact

Moves lab maintenance from reactive to planned: faster fault discovery, fewer surprise failures, one view of the whole lab. Manual checks that took 15 minutes to know the issues and anomalies now take 3-5 minutes since AI is now the one who checks and the human is freed up for more strategic tasks.
