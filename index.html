AEGIS: Cloud-Based Diagnostics & Predictive Analytics

Capstone · Cebu Eastern College, Incorporated · College Teachers & Education Instructors

AEGIS is a cloud-based web application that checks PCs automatically using agent technology, shows their health live, and predicts which machines will need maintenance before they break.

The problem
Faults surfaced during classes, disrupting education instructors. Maintenance was reactive, with no reliable record of which machines kept failing, requiring manual checks one by one.
The solution
Agent technology installed on each PC reports hardware and software diagnostics to a cloud-based server. A web dashboard shows live status, and predictive analytics flags machines likely to need service.
My role
UI/UX design and web development. I designed the dashboard and status system in Figma, built the front end, and connected it to the diagnostics and prediction data.
Tech stack
Figma HTML5 / CSS3 / JavaScript Tailwind CSS Node.js / PHP REST API SQL Python

Design system

One three-state colour code (healthy, watch, at risk) used across every workstation tile, chart and alert, so instructors and IT staff can read a system's condition at a glance. Dashboards put the machines needing action first.

Technical integration

Software agents send diagnostics to the cloud server in real time. The web application reads that stream for live monitoring and feeds the history into the predictive model for maintenance forecasts.

Impact

Moves maintenance from reactive to planned: faster fault discovery, fewer surprise failures during instruction, and one view of all systems. Automated manual diagnostic workflows using agent technology, cutting issue detection time from 15 minutes down to 3–5 minutes while reallocating human effort toward strategic initiatives.
